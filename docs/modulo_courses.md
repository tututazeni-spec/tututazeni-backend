### Ao clicar em "Criar Curso"

No que já existe, acrescenta: **Estado**

**Tipos:**

Obrigatório, Opcional, Compliance, Integração, Desenvolvimento, Técnico, Comportamental, Liderança

### 2 — Estrutura

Estrutura do curso: Módulos, Lições, Secções, Ordem, Duração estimada, Conteúdo obrigatório, Conteúdo opcional

**Cada módulo pode conter:**

- Título
- Descrição
- Ordem
- Duração

**Cada lição:**

- Título
- Tipo
- Conteúdo
- Duração
- Obrigatória
- Ordem

**Tipos de lição:**

Vídeo, PDF, Documento, Apresentação, Texto, Áudio, SCORM, Link externo, Conteúdo interactivo, Aula ao vivo

### 3 — Conteúdos

Permitir associar: Vídeos, PDFs, documentos, apresentações, áudios, imagens, links, SCORM, conteúdos da Biblioteca

### 4 — Avaliação

**Configurar:**

- Avaliação final
- Questionários
- Testes
- Número de tentativas
- Nota mínima
- Tempo limite
- Embaralhamento de perguntas
- Correção automática
- Feedback
- Aprovação obrigatória

**Exemplo:**

- Nota mínima: 70%
- Máximo de tentativas: 3

A avaliação utiliza o motor de avaliações/questionários existente, sem transformar o curso num segundo módulo Evaluation.

### 5 — Inscrição

**Definir quem pode frequentar:**

- Todos os colaboradores
- Unidade
- Departamento
- Cargo
- Função
- Grupo
- Colaboradores selecionados

**Também:**

- Inscrição automática
- Inscrição manual
- Autoinscrição
- Aprovação necessária

### 6 — Modalidade

Online, Presencial, Híbrido, Ao vivo, Autoaprendizagem

**Para presencial/híbrido:**

- Local
- Sala
- Datas
- Horário
- Formador
- Capacidade

**Para aulas ao vivo:**

- Data
- Hora
- Link
- Instrutor
- Plataforma

A ligação deve ser feita ao módulo Live Classes, não duplicar a gestão das aulas ao vivo dentro de Cursos.

### 7 — Conclusão

**Definir requisitos:**

- Percentagem mínima de progresso
- Lições obrigatórias
- Nota mínima
- Avaliação obrigatória
- Presença obrigatória
- Projeto/trabalho obrigatório

**Exemplo:**

> Curso concluído quando o colaborador atingir 100% das lições obrigatórias + 70% na avaliação final.

### 8 — Certificação

**Configurar:**

- Emitir certificado
- Modelo de certificado
- Nome no certificado
- Código
- Data de emissão
- Validade
- Assinatura
- Responsável

### 9 — Publicação

Rascunho, Em revisão, Publicado, Suspenso, Arquivado

**Antes de publicar:**

- Pré-visualizar curso
- Validar estrutura
- Validar conteúdos
- Validar avaliação
- Validar requisitos
- Publicar

### Dentro de cada curso

Ao clicar num curso existente, abas propostas:

Resumo, Conteúdo, Módulos, Formandos, Progresso, Avaliações, Presenças, Discussões, Materiais, Certificados, Relatórios, Configurações

**Resumo:**

- Descrição
- Objetivos
- Público-alvo
- Duração
- Modalidade
- Instrutor
- Estado
- Número de formandos
- Taxa de conclusão
- Classificação média

**Conteúdo:**

Módulo 1 → Lições → Conteúdos

Exemplo:

> Módulo 1 — Introdução → Lição 1 — Introdução ao tema → Lição 2 — Conceitos fundamentais → Lição 3 — Vídeo → Questionário

## Integrações importantes

O módulo Cursos deve conversar diretamente com:

- **Colaboradores** → quem aprende
- **Percursos de Aprendizagem** → agrupamento de cursos
- **Live Classes** → aulas ao vivo
- **Evaluation** → avaliações formais, quando aplicável
- **Biblioteca** → conteúdos e documentos
- **Competências** → competências desenvolvidas
- **PDI** → necessidades de desenvolvimento
- **Carreira** → cursos recomendados
- **Liderança** → programas de desenvolvimento de líderes
- **Notificações** → lembretes e avisos
- **Certificação** → emissão do certificado

## Arquitetura que eu usaria

```
Cursos → Módulos → Lições → Conteúdos → Avaliações → Inscrições → Progresso → Conclusão → Certificado

Percursos de Aprendizagem → Curso A → Curso B → Curso C
```

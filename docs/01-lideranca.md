# Liderança — Distribuição pelos módulos existentes

A liderança **não constitui um módulo novo**. É distribuída pelos módulos existentes, tratando cada um uma parte diferente da jornada de liderança.

---

## Resultado final da arquitetura

A liderança atravessa a INNOVA desta forma:

| Módulo | Pergunta que responde |
|---|---|
| Organization | Onde estão as posições de liderança? |
| Competências | Que competências um líder precisa ter? |
| Carreira | Qual é o percurso para chegar a uma posição de liderança? |
| Carreira → Sucessão | Quem pode ocupar essa posição no futuro? |
| Evaluation 360º | Como o líder é percecionado pelas pessoas? |
| Desempenho | Que resultados o líder e a sua equipa apresentam? |
| Planos de Desenvolvimento | O que o líder precisa desenvolver? |
| Trainings | Que programas e formações desenvolvem essas capacidades? |
| Onboarding | Como integrar/preparar alguém que assume uma nova posição de liderança? |

**A jornada fica:**

Potencial → Carreira → Sucessão → Avaliação → Gaps → PDI → Programa de Liderança → Experiência Prática → Nova Avaliação → Progressão

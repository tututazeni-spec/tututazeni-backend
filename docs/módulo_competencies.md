## Integrações principais

O Competencies deve funcionar como o núcleo da gestão de competências, mas não deve absorver os outros módulos:

- **Users** → quem possui a competência
- **Departments** → onde a pessoa está
- **Cargos** → que competências são exigidas pelo cargo
- **Evaluation** → avaliação da competência
- **Evaluation 360°** → feedback de múltiplos avaliadores
- **Development Plans/PDI** → plano para eliminar o gap
- **Trainings** → formação usada para desenvolver a competência
- **Courses** → conteúdos associados ao desenvolvimento
- **Career** → competências necessárias para progressão
- **Succession** → competências necessárias para posições críticas
- **Talent Development** → desenvolvimento de talento

Dessa forma, o Mapa de Competências existente pode consumir os dados deste módulo, em vez de manter uma segunda base de competências separada.

# Post-mortems

Um ficheiro por incidente: `AAAA-MM-DD-titulo-curto.md`, a partir de `docs/deploy/postmortem-template.md`.

- Quando escrever, prazos e princípios sem culpas: `docs/deploy/gestao-incidentes.md`.
- Sem nomes de pessoas, só papéis. Cada acção tem dono (papel) e data.
- O resumo para clientes (3–5 frases) também vai para `ops/status-page/incidents.json` e, se relevante, para as Novidades.
